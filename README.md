# Enterprise Identity Reference Architecture

A vendor-agnostic reference architecture for governing identity across workforce, non-human, privileged, and AI agent categories under one consistent set of principles.

## Read the Architecture

[Enterprise Identity Reference Architecture](enterprise-identity-reference-architecture.md)

## What It Covers

- Five design principles that apply regardless of vendor: continuous verification, deterministic enforcement, least privilege by default, non-human identity as a first-class citizen, continuous evidence generation
- A single Policy Decision Point / Enforcement Point / Information Point / Administration Point model applied consistently across workforce identity, non-human identity, privileged access, secrets, and AI governance
- Four architecture decision records documenting the key tradeoffs
- A governance operating model and phased adoption roadmap
